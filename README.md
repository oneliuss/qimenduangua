# 🐉 astrbot_plugin_qimen · 奇门遁甲断卦插件

一个适用于 [AstrBot](https://github.com/Soulter/AstrBot) 的奇门遁甲断卦插件。根据用户提出的问题和当前时间，**起局排盘**，并依古法与现代体系（以《御定奇门宝鉴》《奇门法窍》《烟波钓叟歌》及张志春《神奇之门》《开悟之门》《奇门真髓》《奇门精粹》为本）**直接给出吉凶判断与实操建议**。

支持命令调用，也支持**自然语言**触发（无需斜杠前缀）。

---

## ✨ 功能特性

- **时家奇门·转盘法**：按时辰干支与节气定局（阳遁顺布、阴遁逆布），自动判阴阳遁与上中下元。
- **日干支定元**：以节气起始日为基准，每5日一元（第1-5日上元、6-10日中元、11-15日下元），精确对应古法"每元五日"之制。
- **四盘排布**：地盘六仪三奇、天盘九星+天盘干、人盘八门、神盘八神，含中宫寄宫。
- **八门飞布**：直使门加临时支所在宫，其余八门按九宫飞布顺序转动（阳遁顺飞、阴遁逆飞），中宫无门跳过。
- **直符直使**：按时柱旬首定直符宫、直符星、直使门。
- **十干克应**：天盘干加地盘干的组合断吉凶（依《神奇之门》），含70+组克应关系。
- **六仪击刑**：检测仪加刑宫，主灾咎破败（依《御定奇门宝鉴》）。
- **三奇入墓**：精确检测乙丙丁三奇入墓库（依《奇门法窍》）。
- **格局识别**：三诈格（真诈/重诈/休诈）、玉女守门、青龙返首、飞鸟跌穴、人遁/神遁吉格（吉）；伏吟、反吟、门迫、白虎猖狂、腾蛇妖娇、太白入荧、荧入太白、大格、小格、刑格、悖格、朱雀入江、天网四张、青龙逃走（凶）。
- **门宫生克**：门迫（门克宫，凶）、门义（门生宫，吉）、门和（宫生门，吉）、门制（宫克门，凶）。
- **八门旺衰**：依月令查八门旺相休囚死状态（依《奇门真髓》）。
- **空亡转宫**：旬空对冲之宫为转宫，断事以转宫论（依《神奇之门》）。
- **主客关系**：天盘为客、地盘为主，天盘生地盘利客，地盘生天盘利主（依《神奇之门》）。
- **用神选取**：按问题匹配用神（生门主财、开门主出行官职、景门主考文、天芮主病、天心主医、六合主婚、玄武主失物、伤门主争竞、惊门主官非等），用神含义详注。
- **空亡驿马**：旬空落宫、驿马落宫自动标注。
- **应期推断**：空待填实、伏待冲、旺待墓、衰待生、临马看值马之期、空亡看转宫。
- **自然语言触发**：含「奇门/遁甲/起局/排局」等意图即识别并自动提取问题。
- **图形化配置**：通过 `_conf_schema.json` 声明配置，AstrBot 管理面板自动渲染为下拉框与开关界面。

## 📦 安装

将整个 `astrbot_plugin_qimen` 文件夹放入 AstrBot 的插件目录：

```
data/plugins/astrbot_plugin_qimen/
├── main.py            插件入口（命令注册、报告格式化）
├── qimen.py           奇门遁甲起局排盘
├── qimen_duangua.py   奇门遁甲断卦（吉凶判断）
├── qimen_yuce.py      预测模块（趋势/成败/应期/风险）
├── qimen_yunchou.py   运筹模块（择吉方位/时机/策略/主客）
├── qimen_fengshui.py  风水模块（环境方位/吉凶方位/布局）
├── qimen_shiren.py    识人模块（性格/才能/关系/用人）
├── qimen_zhexue.py    哲学模块（易理/格局之智/人生启示）
├── qimen_data.py      奇门遁甲静态数据
├── metadata.yaml      插件元数据
└── _conf_schema.json  配置项定义
```

随后在 AstrBot 管理面板「插件管理」中重载插件，或重启 AstrBot 即可生效。

> 本插件除 AstrBot 自身运行环境外**无额外第三方依赖**。

## 🕹️ 使用方法

### 命令方式

| 命令 | 说明 |
|------|------|
| `/qimen <问题>` | 起局断卦（吉凶判断+建议） |
| `/奇门 <问题>` | 同上 |
| `/qm <问题>` | 同上 |
| `/qm_yuce <问题>` | 预测：事体发展趋势与成败概率 |
| `/qm_yunchou <问题>` | 运筹：择吉方位与行动策略 |
| `/qm_fengshui <问题>` | 风水：环境方位与布局建议 |
| `/qm_shiren <问题>` | 识人：性格才能与人际关系 |
| `/qm_zhexue <问题>` | 哲学：易理启示与人生智慧 |
| `/qm_all <问题>` | 综合分析（断卦+预测+运筹+风水+识人+哲学） |
| `/qm_help` | 查看使用说明 |

### 五大专项模块

| 模块 | 功能 | 侧重 |
|------|------|------|
| 🔮 **断卦** | `/qimen` | 吉凶判断、格局分析、门宫生克、应期建议 |
| 📊 **预测** | `/qm_yuce` | 事体发展趋势、成败概率、发展阶段、风险预警 |
| 🧭 **运筹** | `/qm_yunchou` | 最佳方位、择吉时机、主客攻守、行动策略 |
| 🏠 **风水** | `/qm_fengshui` | 环境总评、吉凶方位、关键宫位、布局建议 |
| 👤 **识人** | `/qm_shiren` | 性格特质、才能优势、短板不足、人际关系 |
| 📜 **哲学** | `/qm_zhexue` | 核心易理、格局之智、阴阳之道、人生启示 |

### 自然语言方式（无需斜杠）

含奇门意图的句子即可触发断卦，插件会自动识别意图并提取问题：

```
奇门遁甲 测下这笔生意能不能做
帮我起个奇门局 明天出行顺利吗
用遁甲看看近期财运
排个局 近期工作有着落吗
```

### 用法举例

```
/qimen 这笔投资能做吗
/qm_yuce 这笔生意的前景如何
/qm_yunchou 明天出行哪个方向好
/qm_fengshui 新办公室布局建议
/qm_shiren 我的合作伙伴怎样
/qm_zhexue 这件事给我什么启示
/qm_all 这笔投资能做吗
```

> 问得越具体，用神越准，断语越贴合（财/官/病/考/婚/行人/失物各有对应用神）。奇门以门/星/神取用。

## ⚙️ 图形化配置界面

**入口**：AstrBot 管理面板 -> 插件管理 -> 找到「astrbot_plugin_qimen」-> 点击「配置」。

| 配置项 | 界面控件 | 默认值 | 可选项 | 说明 |
|--------|----------|--------|--------|------|
| `show_disclaimer` | 开关 | `true` | - | 是否在每次断卦结果末尾附上理性看待的免责声明 |
| `advice_style` | 下拉框 | `modern` | `modern` / `classic` | 建议风格：`modern`=白话实操；`classic`=古法直断（偏文言） |
| `enable_duangua` | 开关 | `true` | - | 启用【断卦】模块，关闭后 /qimen、/奇门、/qm 及奇门意图自然语言触发不可用 |
| `enable_yuce` | 开关 | `true` | - | 启用【预测】模块，关闭后 /qm_yuce 及预测意图触发不可用，综合分析也会跳过 |
| `enable_yunchou` | 开关 | `true` | - | 启用【运筹】模块，关闭后 /qm_yunchou 及运筹意图触发不可用，综合分析也会跳过 |
| `enable_fengshui` | 开关 | `true` | - | 启用【风水】模块，关闭后 /qm_fengshui 及风水意图触发不可用，综合分析也会跳过 |
| `enable_shiren` | 开关 | `true` | - | 启用【识人】模块，关闭后 /qm_shiren 及识人意图触发不可用，综合分析也会跳过 |
| `enable_zhexue` | 开关 | `true` | - | 启用【哲学】模块，关闭后 /qm_zhexue 及哲学意图触发不可用，综合分析也会跳过 |
| `enable_zeri` | 开关 | `true` | - | 启用【择日】模块，关闭后 /qm_zeri 及择吉意图触发不可用 |

> 修改后保存即可，下次起局立即生效，无需重启。

## 🔮 古法实现说明

起局排盘采用**时家奇门·转盘法**，综合《烟波钓叟歌》《御定奇门宝鉴》《奇门法窍》古法与张志春《神奇之门》《开悟之门》现代体系：

```
定时柱 -> 节气定局(阴阳遁+上中下元) -> 排地盘六仪三奇 -> 定直符直使
-> 排天盘九星+天盘干(直符加时干) -> 排人盘八门(直使加时支) -> 排神盘八神
-> 十干克应 -> 击刑入墓 -> 格局吉凶 -> 主客关系 -> 空亡转宫 -> 断吉凶应期
```

- **九宫**：洛书数坎1 坤2 震3 巽4 中5 乾6 兑7 艮8 离9，中宫寄坤2宫。
- **节气定局**：冬至至芒种用阳遁（顺布），夏至至大雪用阴遁（逆布）；每节气分上中下三元，局数1-9。
- **日干支定元**：以节气起始日为基准，每5日一元（第1-5日上元、6-10日中元、11-15日下元），精确对应古法"每元五日"之制。
- **六仪三奇**：戊己庚辛壬癸为六仪（对应六甲旬首），丁丙乙为三奇；阳遁戊从局数宫起顺飞，阴遁逆飞。
- **直符直使**：按时柱所在旬首（甲子戊/甲戌己/甲申庚/甲午辛/甲辰壬/甲寅癸），找该仪在地盘所在宫，即为直符宫，对应九星为直符星、八门为直使门。
- **天盘九星+天盘干**：直符星加临时干所在宫，其余九星按九宫顺序顺/逆转动；天盘干同理，直符仪随天盘星飞布。
- **人盘八门飞布**：直使门加临时支所在宫，其余八门按九宫飞布顺序随之转动（阳遁顺飞洛书序1->2->3->4->6->7->8->9，阴遁逆飞），中宫无门跳过。
- **神盘八神**：直符神随天盘直符星所在宫，按「直符腾蛇太阴六合白虎玄武九地九天」顺序转动。
- **十干克应**（《神奇之门》）：天盘干加地盘干，70+组组合断吉凶（如戊加戊青龙返首吉、庚加戊白虎猖狂凶、丁加癸朱雀入江凶等）。
- **六仪击刑**（《御定奇门宝鉴》）：仪加本刑之宫（戊刑震、己刑坤/艮、庚刑艮、辛刑离、壬刑坎、癸刑巽），主灾咎破败。
- **三奇入墓**（《奇门法窍》）：乙奇入乾、丙奇入乾、丁奇入艮，谋为不通。
- **格局**：三诈格（三奇临吉门，分真诈/重诈/休诈）、玉女守门、青龙返首、飞鸟跌穴、人遁/神遁（吉）；伏吟、反吟、门迫、白虎猖狂、腾蛇妖娇、太白入荧、荧入太白、大格、小格、刑格、悖格、朱雀入江、天网四张、青龙逃走（凶）。
- **门宫生克**：门克宫为门迫（凶）、门生宫为门义（吉）、宫生门为门和（吉）、宫克门为门制（凶）。
- **八门旺衰**（《奇门真髓》）：依月令查八门旺相休囚死（如休门旺冬、生门旺四季月、景门旺夏等）。
- **空亡转宫**（《神奇之门》）：旬空对冲之宫为转宫，断事以转宫论（如坎空转离、坤空转艮）。
- **主客关系**（《神奇之门》）：天盘为客（动方）、地盘为主（静方），天盘生地盘利客，地盘生天盘利主。
- **应期**：空待填实、伏待冲、临马看值马之期、空亡看转宫、反吟主速应期近、伏吟主迟待冲。

### 吉凶等级

综合用神旺衰、生克、格局、十干克应、击刑入墓等给出评分，映射为：大吉 / 吉 / 小吉·中平 / 小凶 / 凶 / 大凶。
